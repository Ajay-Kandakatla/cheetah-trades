**Status: display only, nothing measured, nothing claimed.** The cards draw the print the ticker page already shows. Scans,
bands, the ledger and the 📐 page still read closed bars. Nothing is written to any cache.

## The ask, verbatim

Ajay 2026-10-16 ~11:00–11:10 ET, three messages:

1. > "Can you make this chart more live please like when its 24 hour or todays entry"

   With a screenshot: the XLAB Chart Maps card, daily candles, today's candle with a dashed **"now 2.64"** line, header

## The divergence found

Three causes, all on the card side (the ticker page was right):

- **Cadence.** The card is the board payload `GET /chart-maps?tab=…`, refetched every `BOARD_REFRESH_MS` (5 minutes,
  `frontend/src/pages/ChartMaps.tsx`). The ticker page (`SessionPrice.tsx`) polls `GET /sepa/live-price/{sym}` every
  30 s.
- **Candle close.** The board's today bar comes from `prices.with_today_bar`, whose RTH close is the snapshot's `day.c`.
  The page's number is the LAST TRADE (`quote_view`: `last_trade_price` first). The two differ through the session.
- **Two snapshot fetches.** The candle (`_attach_bars` → `bars_for` → `with_today_bar`) and the now line
  (`attach_live_now` via `_live_snapshot` / `bulk_live_prices`) were read from two separate snapshot calls, so even
  inside one board read the candle and the line could disagree.

## What ships

- **`POST /chart-maps/live`** (`backend/chart_maps/api.py` → `backend/chart_maps/live_card.py`), body
  `{"symbols": [...]}`. ONE `prices.bulk_snapshot` + ONE `prices.bulk_cached_frames` (a Mongo find, never a fetch).
  Per symbol the card's last bar is built by CALLING the board's own chain — `prices.with_today_bar` →
  `board._norm_frame` → `board._frame_to_bars` → `board._tag_live_bar` — and the now block by calling
  `board.attach_live_now` on a probe tile. In RTH the candle closes at the last trade with high/low widened to it
  (`live_card.CLOSE_FOLLOWS_PRINT_RTH = True`, HIS CALL Q2); a print of another day or session never touches the bar.
  Pre-market and after hours keep the board's existing shapes and the `s: "pre"|"ah"` shading.
- **The cap** = `prices._SNAP_CHUNK` by name (`live_card.cap()`), one snapshot call. Above it the read is refused whole
  (413), never cut. `board.LIMIT_MAX` is below the cap, so one request per board.
- **One symbol that fails never fails the read** (AMENDMENTS8 C2): it is omitted and named in `faults`. A snapshot that
  answers nothing — or a read where every asked symbol faulted — is a `fault` with an empty footer: a read that served
  nothing claims no "live · …" time.
- **The cards poll** (`frontend/src/hooks/useCardLive.ts`, constants in `frontend/src/lib/cardLive.ts`):
  `CARD_LIVE_MS = 30_000` (MINE, = the ticker page) while the tab is on screen; `CARD_LIVE_CLOSED_MS = 30 * 60_000`
  (Cheetah default, = `drop10_tab.CLOSED_TTL_SEC`) when the session is closed. The pacing session is the BOARD's
  `tape_session` first, then the last good answer (C1). One tick right after every board refetch (C3), except while
  closed. No POST while `document.hidden`, none while one is in flight; back on screen after more than a cadence → one
  POST at once; unmount aborts. "24 hour" = 04:00–20:00 ET: the snapshot carries no overnight-venue prints (C7).
- **The patch** (`lib/cardLive.patchTile`): a served bar with the tile's last date replaces the last bar; a newer bar
  whose `prev_t` is the tile's last date is appended (never a slide), with the served `prev_bar` (closed, no `s`) first
  replacing the tile's last bar (C4); an older bar, a Winners window or an intraday tile → bars unchanged. Tone-`now`
  lines take the served price and label. The served footer word joins the existing `cm-scanstamp` line. The FE composes
  no word.
- **Unchanged**: the 5-minute board refetch (bands, chips, order), the 🔻 / 🎢 60 s cadences, `PatternChart.tsx`,
  `lib/chartMaps.ts`, every scan, every alert.

## Every served string (W-table, `backend/chart_maps/live_card.py`)

| # | Key | Exact text | Source |
|---|---|---|---|
| W1 | `footer.live` | `live · {HH:MM:SS} ET`; `None` when the session is `closed` or on a `fault` | `live_card.footer`, server ET clock |
| W2 | `footer.stale` | `last refresh {HH:MM} ET`; `None` on a `fault` | `live_card.footer` |
| W3 | `fault` | `live quotes unavailable — the cards keep the board's last read` | `live_card.FAULT_TEXT` |
| W3b | `faults[SYM]` | `live quote unavailable for this symbol — the card keeps the board's last read` | `live_card.SYMBOL_FAULT_TEXT` |
| W4 | 413 `detail` | `up to {cap} symbols per live read — {n} sent` | `live_card.too_many_text`, cap = `prices._SNAP_CHUNK` |
| W5 | 422 `detail` | `symbols must be a list of tickers` | `live_card.BAD_BODY_TEXT` |
| W6 | `now.label` | `now` / `now · pre` / `now · AH` | `board.now_label` via `attach_live_now` on the probe |
| W7 | `now_labels` | `["now", "now · pre", "now · AH"]` | `live_card.now_labels()` → `board.now_label` |
| W8 | `now.as_of` | `{HH:MM:SS} ET` of the print | `prices.extended_print(snap)["epoch"]` in ET |
| W9 | `as_of` | `{YYYY-MM-DD HH:MM:SS} ET` | compose clock |
| W10 | `bar.s` | `pre` / `ah` | `board._tag_live_bar` |

The " · " is U+00B7 (the `now_label` glyph). The FE adds no literal; the contracts block "🔴 live card overlay
(2026-10-16)" pins that.

## Cost

- One Massive snapshot REST call (≤ `prices._SNAP_CHUNK` names) + one Mongo find per 30 s per open, visible board tab.
  Two tabs or two people = two. While closed: one per 30 minutes. The ticker page already makes the same snapshot call
  per name every 30 s.
- No WS, no SSE, no focus-list change (the ONE Massive WS connection rule).
- The 5-minute board refetch is unchanged, plus one extra POST right after each refetch (C3).

## Read-only proof

- `backend/tests/test_chart_maps_live_card.py`: a source guard (no cache-writer name in `live_card.py`, comments
  included), a behavioural guard (`load_prices`, `_fetch`, `_mongo_put`, `_parquet_put`, `patch_latest_closes`,
  `purge_weekend_bars` monkeypatched to raise → the RTH golden still passes, the input frame untouched).
- The live check below: `price_cache.cached_at` read before and after the POSTs → equal.

## Known gaps

- Board-time reads (the AMD today raid, 🔑, 🎯, ⚡, bands, sort order) stay up to 5 minutes behind the moving candle.
- An appended bar has no MA / volume-average value until the next board refetch (curves are index-aligned).
- A cold symbol (no `price_cache` doc) gets the line only, no bar.
- A snapshot outage and a board of only unknown symbols read the same (`fault`).
- At 16:00:00 sharp the served `session` says `rth` while the print says after hours; the bar and label follow the print
  (the board's own behaviour).

## HIS CALLS (BUILD_SPEC8 §7 + AMENDMENTS8; each ships with the default shown)

- **Q1** (K1) Card refresh while on screen: every 30 s (default, = the ticker page) · 15 s · 60 s.
  `lib/cardLive.CARD_LIVE_MS`.
- **Q2** (K2) In market hours the candle's close follows the last trade, high/low widened to it (default, = the page) ·
  keep Massive's day close and move only the line. `live_card.CLOSE_FOLLOWS_PRINT_RTH`.
- **Q3** (K3) Pre-market and after hours move the candle and the line (default ON — what the board already draws) · RTH
  only (needs the board's own pre/AH bars changed too, else the 5-minute refetch redraws them).
- **Q4** (K4) The 5-minute full board refetch stays for bands, chips and order (default) · faster.
- **Q5** Closed hours (20:00–04:00, weekends, holidays): re-read every 30 min (Cheetah default =
  `drop10_tab.CLOSED_TTL_SEC`) · stop polling while closed · 5 min. With 30 min the first 04:00 pre-market print can
  reach the overlay up to 30 min late (the 5-minute board refetch still brings it).
- **Q6** The line under the toolbar while closed: "last refresh HH:MM ET" (default) · "live · HH:MM:SS ET" around the
  clock.
- **Q7** Scope: every tile on every board tab (default) · also the 🔍 Support / 📁 My holdings daily tiles (own
  endpoint). Gajjala's 5-minute tiles and the 🧭 index strip are not daily cards and stay as they are.
- **Q8** Demand / VCP cards that have no now line in market hours: the candle moves, no line is added (the board's rule,
  default) · add a now line there too.
- **Q9** After each board refetch the board refetch wins for one tick, then the overlay re-applies at once (default, C3)
  · keep the last live overlay across a refetch.
- **Q10** Coming back to a backgrounded tab re-reads at once (default) · wait for the next tick.
- **Q11** An old print (a thin name, hours since its last trade) still moves the line (default, the board's rule) · hide
  prints older than N minutes. (C5: `now.as_of` is served but not rendered — no new chrome.)
- **Q12** The footer words "live · HH:MM:SS ET" / "last refresh HH:MM ET" (D6) · other wording.
- **Q13** (C6) In market hours the high/low widen to the last print, so a late re-reported print that Massive's day
  high/low exclude can draw a wick until the next refetch (default: keep, D1) · widen only the close.
- **Q14** (C7) "24 hour" = 04:00–20:00 ET: the snapshot carries no 20:00–04:00 overnight-venue prints and
  `trade_session` calls them closed (default) · source an overnight feed.

From the builders:

- **(a)** The served per-symbol `faults` map is not read by the FE. Default: kept served, unread · drop it · render it
  on the card.
- **(b)** A row with no last trade moves the now line to the day close (the board's own rule, `_snapshot_print` falls
  back to `price`) · leave the line where the board put it.
- **(c)** On a Saturday the Friday bar is served as `s: "ah"` with close = Friday's 19:00 print (`with_today_bar`'s own
  after-hours branch; matches the board) · serve Friday's regular close untagged.
- **(d)** While CLOSED a board refetch drops the overlay and the next re-read waits up to 30 min, so a card can show
  `day.c` for that long (D3 outranks C3 there) · keep the last good overlay on closed refetches.
