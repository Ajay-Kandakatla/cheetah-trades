# Worktree `frontend/node_modules` symlink ignored (2026-11-16)

Every `.wt-*` worktree symlinks `frontend/node_modules` to the main tree's
install. The root `.gitignore` carried `node_modules/`, a directory-only
pattern that does not match a symlink, so the link showed as `??` untracked and
a `git add -A` would have committed it. The pattern is now `node_modules` (no
trailing slash), which ignores the symlink and real directories alike. Pinned by
`backend/tests/test_repo_hygiene_2026_11_16.py` (positive: the symlink path is
ignored as a non-directory; negatives: the directory-only form, commented and
negated forms, a lookalike prefix, and real source files are not ignored).
`.venv/` has the same directory-only shape; it is not changed here.
