## The latch

BUILT his answer: `GC.HIGH_SI_CROSS_LATCH = "cross"` — one push per name, chart and cross (the claim id carries the
bar time). A second pass on the same bar is `claimed_before`; a later up cross the same session on the same chart
rings again. `"session"` (and ANY unknown value — fail closed) = once per name, chart and session. The tag
`ggs-{tf}-{SYM}-{HHMM}` carries the bar time so a second cross is a NEW notification (sw.js sets no `renotify`).

## What never rings

A cross under (bearish) · a name the board does not list (every not-listed reason, the two-float disagreement
included) · today's first drawn bar (the watch rule — it has no prior bar on the chart) · the candle still printing
(the pass's frames are closed bars only) · a closed day · before 04:00 / after the extended close · a candle that
started in his first 15 minutes · under GG's session floor or an unknown volume · a dry / on-open pass · a run with
the mode off · a store without an alert collection.

## Missed crosses are lost

A cross is judged only on its own bar. A skipped or slept pass, a name over the pass's bar budget (no frame that pass)
or a cross held on its own bar (floor, mute, hours) is counted `late` on the next pass and is **never sent late**. The
15-min candle is fresh only for the :01 / :16 / :31 / :46 passes.
