## The checks (inputs: the stored read + its own frame's stored bars and EMA curves)

| key | ✓ when | n/a when (`why`) |
|---|---|---|
| `base_bars` | `base.bars` ≥ the setup's bound | no base / bad count (`no_base`) |
| `near_high` | trigger within 15% of the day's high so far (`detectors.day_high_before`, premarket included; a broke read looks only at bars before its entry bar) | no trigger (`no_trigger`), entry bar not on the stored bars (`entry_off_chart`), entry is the first bar (`no_bars_before`), no bars (`no_bars`) |
| `tennis_drop` (🎾) | the drop is 15%+ — exact when the read carries `tennis.from_hi`; otherwise bounded: from the drop bar's own high (low bound) to `max(hd, min(close_k ÷ (1 − K8_RECOVER_PCT%), day high))` (high bound). ✓ only when the low bound passes, ✗ only when the high bound fails | no tennis ball on the read (`no_tennis`), the range straddles 15% (`tennis_between`) |
| `ema_hold` | every base close at or above the setup's EMA (zero tolerance) | base off the stored chart (`base_off_chart`), an EMA value missing / curve mis-sized (`ema_warming`) |
| `lower_highs` (🎾, ⓘ) | never — always `ok: None`, `info: True`, value = count of swing highs (`price_zones._local_extrema`, `VCP_PIVOT_WINDOW`) lower than the one before | fewer than two swing highs (`few_swings`) |

**Printing at the bound (2026-11-27 refix).** Stored percentages keep 1 decimal, except where that would land on or across the 15% bound from the other side: then 2 decimals, rounded away from the bound (`_rnd`). A trigger 15.04% under stores 15.04 and prints "15.04% under …" and the chip "🧘 15.04% under high", never "15%" beside "within 15%". The chip's whole number gives way to the stored decimals when it would read as the bound (15.4% → "🧘 15.4% under high"; a 14.6% tennis ball → "🧘 14.6% tennis ball"). An older stamp holding exactly 15.0 prints "15.0". The ✓ / ✗ itself is unchanged — it is judged on the unrounded number.

**Verdict (counted checks only):** any ✗ → `not`; else at most `MAX_NA` n/a → `gg_like` (chip `🧘 GG-like`); else `unknown` (chip `🧘 can't tell`). An info row never fails and never spends `MAX_NA`.

## Limits

- Hand-picked examples, third-party labels, small n, prior NULL (11-26 smooth-vs-run study: no difference). Never read "calmer runs further" into it.
- The tennis-ball size is bounded, not exact: the read does not keep the high it fell from. A straddle is n/a, so a small ball whose recovery overshot can still read 🧘 GG-like.
- The stored read is the END-OF-DAY read: a name that moved on no longer describes its ring (survivorship). Only a block frozen at the ring is a fair record.
- The 15% high bound cuts one valid example (NXTP ~16–19%). The fade's 9 comes from a 15-minute chart.
- `need` is frozen inside every block: a later bound change re-judges new reads only.
- The chip word over-claims: 6 of his 11 invalid charts pass these same checks.
