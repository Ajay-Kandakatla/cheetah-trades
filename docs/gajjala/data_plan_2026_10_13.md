# Gajjala's tab — data plan (WP1, 2026-10-13)

The data spine under the 🚩 Gajjala's tab: ONE whole-market Massive snapshot per 5-minute pass, his scanner over it,
closed 5/15-minute bars for the listed names, and the Mongo collections the endpoint reads. Nothing here scans or
fetches on a page load. Every number lives in `backend/chart_maps/gajjala/constants.py` with its provenance (GG =
his own words, Ajay K#/H# = Ajay's answers 2026-10-13, "Cheetah default" = Ajay's number, not Gajjala's).
UNMEASURED: nothing here says these setups win.

## 1. The whole-market snapshot (`sepa/prices.py`)
- `market_snapshot_with_meta(include_otc=False) -> (rows, meta)`: ONE `GET /v2/snapshot/locale/us/markets/stocks/tickers`
  with no `tickers` param, `include_otc=false`, timeout 30 s, through the keep-alive `prices._http()`.
  `meta = {http, wall_s, bytes, n}` (+ `error`). Non-200, transport error or no key → `({}, meta)`, never a raise; the
  exception text goes through `_scrub_key` (the URL carries the key).
- Every item goes through `_snapshot_row(item)` — extracted from `bulk_snapshot` so the two can never drift
  (byte-identical output pinned in `tests/test_prices_market_snapshot.py`). Keys in our dash spelling (`BRK.B` → `BRK-B`).
- `closed_daily_frame(symbol, *, now=None)`: daily bars dated BEFORE today (ET); the cache is used only when it already
  holds the last weekday before today, otherwise `_fetch` — and nothing is ever written (trap T5: `load_prices` caches
  today's partial bar under the 20 h TTL). For the 🎾 squeeze-history chip (WP2).

Per row, in order: the last print must be dated the session (`prices.extended_print(row).date == session` — overnight rows
carry the LAST session stamped as today, trap T6); `prevDay.c > 0`; the instrument type; then the three numbers. Shares
today = Massive `min.av` (accumulated incl. pre-market) when its minute is dated the session, else `day.v` (HIS CALL 1)
— except a PRE-MARKET print, which never falls back to `day.v` (before the open the day aggregate can be a phantom copy
of the prior session, board.py's phantom-day trap): a stale `min` there reads volume 0, `vol_src: "none"`.
Every edge is the multiplication the tests build (`price >= prev * (1 + 25/100)`), never a division.

- **Strip** (GG S8 43:39–44:37): the population is his scanner minus the change floor (band + 1M shares) inside the same
  instrument set; `runners_100`, `runners_80` (inclusive), `best_change_pct/best_symbol`, `quiet` = no name ≥ +40%
  (`None` when the population is empty — 04:00 with nothing traded is not a quiet market).
- **Tape session of a pass**: `prices.trade_session`, except 20:00–`PASS_CLOSE_ET` (20:05) counts as after-hours — the
  20:01 pass closes the 19:55–20:00 bar and is the last after-hours pass.
- **☀️ K9 carry** (after-hours passes only): EVERY snapshot row in the band and instrument set whose last print is ≥ +10%
  over `day.c`; `commit_ah_carry` REPLACES the session's set each pass (a name that fell back under 10% drops out), and a
  failed/empty snapshot (`http != 200` or `n == 0`) never replaces it — the last after-hours pass that RAN decides.
- **🌙 K10 prefilter**: the same rows ≥ +5% over `day.c` (confirmed with 1-minute bars by WP2).
- **Split hold-out** (HIS CALL 17): new qualifiers only, once per symbol per session, via `drop10_tab.fetch_splits_strict`
  + `split_on`; a split executed today → held out (stored `held`, never listed), counted `held_split`; a raised fetch →
  listed with `split_check: "failed"`, counted.
- **Listed set**: qualified on S, prev(S) or prev(prev(S)) (`catalysts.medical.reaction.prev_market_day` — the `market_hours.reminder` holiday table; `key_levels` is display-only by its import guard, tests/test_key_levels.py), holidays skipped. Each name
  carries `{since, last_qualified, day_n, of}` — `day_n` 1 on a day it qualified, `of` = 3 (its last day listed).
  `graveyard_today` = names whose last qualify was the market day before that window (dropped off TODAY only).
- **Instrument-type map**: Massive `/v3/reference/tickers?market=stocks&active=true`, every type, `TYPES_PAGE_LIMIT`
  1,000 per page, at most `TYPES_MAX_PAGES` (15) calls, fetched ONCE per trading day (first pass; later passes read
  `gajjala_state` doc `"types"`). Only a COMPLETE fetch replaces the map and stamps `as_of` today. A failed or PARTIAL
  fetch (a mid-pagination error or the 15-page cap) merges what it read over the previous map, keeps the old `as_of`,
  records `complete: False` + `last_partial {session, n, calls}`, logs a warning, and the next pass retries (one fetch
  per pass) — so a known ETF/warrant never drops to "type unknown" (which the "list" policy would list). A name the map
  has never seen still reads "type unknown" (listed). Headroom: the RTH probe needed 14 of the 15 calls.

## 3. Bars (`chart_maps/gajjala/bars.py`)
- `frames_for(symbols, session, now, *, load_day, workers=board.BAR_WORKERS, budget_sec=PASS_BUDGET_SEC, stats)`: prior
  market day from the 1-minute cache + today with `force=True`, pre-market and after-hours included; per-name failures,
  names with no bar today and names past the budget are skipped and counted. The loader is asked in Massive's
  spelling (`symbols.for_massive`: MOG-A → MOG.A — Massive returns nothing for the dash form); results stay keyed by
  the listed dash form. A None caused by the provider (the 429 cap, the breaker open, non-200, raised —
  `daytrading.data.last_fetch_failed()`, thread-local) counts `failed`, never `no_bars`.
- `timeframes.resample_ohlcv(raw, "5min" | "15min")` — LEFT-closed, RIGHT-labelled (bucket 10:05 = 10:00–10:04).
- `closed_only(df, now)`: a bucket counts once its right label is `BAR_SETTLE_SEC` (30 s) old.
- EMAs: `orderflow.signals.ema` (9 / 21) over the whole 2-session frame, first `period − 1` bars None.
- `Frames`: `f5`/`f15` (`Frame(o,h,l,c,v,t,session,ema9,ema21,today,df)`), `minutes5`/`minutes15` (the 1-minute bars of
  each of today's closed buckets), `as_of_bar_t5`/`as_of_bar_t15` (+ `as_of_bar_t[frame]`), `raw`.
- `tile_payload(frames, tf) -> {bars, curves, vol_avg}`: today's bars via `support._frame_bars` (`s` flags kept), the 9/21
  EMA curves by stamp, and `vol_avg` from `board._vol_avg_series` over the FULL 2-session frame (WP0a) cut to today's
  stamps — so it has a value from today's first bar. All-None curves / averages are omitted.

## 4. Shared-module fixes (Ajay round C, "fix all four" — two of them here)
- `daytrading/data.py` T1: `load_intraday` decides "today" on the ET clock (`_today_et`) — `utcnow()` made a
  19:00–20:00 EST fetch of the live session cache as a completed day forever.
- `daytrading/data.py` T2: HTTP 429 retries capped at `_CB_TRIP_AFTER` (3) consecutive 429s → one breaker failure,
  return None (was an unbounded `continue`). Every provider-failure return also sets a thread-local flag
  (`last_fetch_failed()` / `clear_fetch_failed()`) so a caller can tell "gave up" from "no bars"; an empty 200 is not
  a failure.
- `sepa/prices.py` `closed_daily_frame`: the cache counts as fresh when it holds `prev_market_day(today)` (the house
  calendar) — `BDay(1)` ignored holidays, so the session after a weekday holiday re-fetched on every call.
