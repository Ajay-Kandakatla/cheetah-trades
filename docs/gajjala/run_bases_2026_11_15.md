## The definition (engine `backend/chart_maps/gajjala/run_bases.py`, pure — never fetches, writes or reads a clock)

On today's 5-minute Frame (bar stamp = the bar's CLOSE time; the 09:35 bar holds 09:30–09:34):

1. **Window.** From the first bar after the 09:30 ET open (`ET_RTH_OPEN`) to the last bar at or before that day's regular
   close — `catalysts.medical.reaction.rth_close_time`: 16:00 ET, **13:00 on a `supply_demand.timeframes.HALF_DAYS` date**
   (2026-11-27, 2026-12-24), so a half day's after-hours bars never count.
2. **A run** starts at a run of at least `RUN_BASE_LEG_MIN_BARS` big green bars in a row (the detectors' own K1 legs,
   `detectors.find_legs`), clipped to the window.
3. **A base** is a pause after such a run — bars that make no new run high — of `RUN_BASE_MIN_BARS`–`RUN_BASE_MAX_BARS`
   printed bars, of any depth, until a bar takes the run's high (the base BROKE at that bar). A pause still open at the
   last bar is FORMING. A pause that never had a K1 run in front of it is not a base. A dip SHORTER than
   `RUN_BASE_MIN_BARS` that a new high ends hands the run's K1 leg back (2026-11-15 critic fix), so the next real pause
   still counts — before the fix a 1-bar red dip used up the leg and the next 6–24 bar base was never counted.
4. **Restart.** A pause longer than `RUN_BASE_MAX_BARS` ends the run (STALLED); the next run starts at a K1 leg whose first
   bar is after the stall and counts from 1. A leg that began inside the stalled pause never starts a run.
5. **Printed bars, not clock time.** The house resampler drops empty buckets, so a halt or an empty 5 minutes adds no bar;
   a resume bar that takes the run high breaks the base like any bar.
6. **The count** on the card = the current run's BROKE bases; a FORMING base reads "base n+1 forming". Earlier runs are
   stored, not drawn.

Each stored base carries `quiet` (`D.k3_vol_ok`) and `shallow` (`D.k3_depth_ok`) for the study ONLY — never served, never a
gate. No "tight" key (K6 is not GG's).

Properties pinned by tests: every BROKE base is identical at every later bar; the total broke count over all runs never
decreases; the card's number drops ONLY when a forming base outlives the max (FORMING → STALLED) or a restart opens a new
run with no base yet (no line).
