## The mechanism

1. **The detector flag.** `detectors.reversal_squeeze(F, …, k3_binding=True)`: the default is the GG5 path and returns
   the same bytes as before. `k3_binding=False` passes `exempt=(K3_VOL_KEY,)` to `_resolve_break`. The K3 row is still
   read and listed (`missed` still names `k3_vol`, its ✗ stays on the card), but it does not bind the state. Nothing
   else is exempted. `K3_VOL_FRAC` is untouched, and no new number exists anywhere.
2. **The break-pass-only rule.** `k3s_candidate(read)` is true only for a 🎾 read in state "partial" with `broke` True,
   `entry_bar_t` set, `bars_since_entry == 0` (the detector's own field), and `missed` exactly `["k3_vol"]`, with no
   unjudged row, no variant and no grade. The detector never flips a K3-partial read: it stays "partial" for the rest
   of the session while `bars_since_entry` climbs. So a name is a candidate **once**, on its break bar. One bar later
   it is not a candidate, and a re-read there would be "triggered", never A+. `k3s_partial(read)` has the same shape
   for any non-empty `missed`, and it is the predicate of the `#partial_break` marker.
3. **K11 re-applied.** A partial read never carries the K11 row, because `k11_gate` only judges aplus, triggered and
   stopped reads. So `missed == ["k3_vol"]` says nothing about K11. The overlay re-applies the ONE gate,
   `detectors.k11_gate(re-read, session volume)`, with the pass's own session volume. This fails closed the same way
   `read_all` does: no figure, or a figure under `GC.K11_MIN_SESSION_VOLUME`, makes the re-read "partial" and nothing
   is admitted. A 🎾 under the 1M floor never rings on 🧪 either.
4. **The same chain as a 🚩 A+.** The admitted re-read goes through `alerts.refusal`, then
   `audited_rules.judge(…, admit="K3S")`, then T1 (it takes a daily-cap slot in 🚩's ring order), the shadow claim and
   the `#held` marker. All of these are exactly what a 🚩 A+ gets. It keeps 🚩's OWN plan (trigger, stop, R and risk %).
   `judge(admit=)` accepts only None or the id of an ON admit rule, and anything else raises `ValueError`.
5. **The audit block** always carries `admit` (None on every non-K3S block, so all blocks have one shape). On a K3S
   block, `original_aplus` is False and the words come from `ADMIT_TEXT_OK` / `ADMIT_TEXT_HELD`:
   "🧪 A+ by K3S — 🚩 reads it 'broke — not A+' · … pass · UNMEASURED" or "🧪 A+ by K3S (🚩 reads it 'broke — not A+'),
   held here by: … · UNMEASURED". The reason is always `detectors.NOT_APLUS_REASON`, never retyped. `with_t1` keeps the
   admit and its words.
6. **The ℹ️ rules panel** gains one sentence after the exit grades: "Admits on the A+ read — a 🧪 A+ 🚩 never rings,
   with 🚩's own plan: K3S …". If K3S is off, the sentence is gone.

## The `#partial_break` marker and the first-wins claim key

- Every 🎾 partial break leaves ONE `#partial_break` marker in the GGA store, whatever it missed: the K3S candidates
  and placebo (a) alike. The id is `{claim_key}#partial_break`, the state is `K3S_PARTIAL_ROW_STATE = "partial_break"`,
  and the record is first-wins (`$setOnInsert`). It is a third state with `#` in the id, so it is never a 🏁 row
  (`LEDGER_ALERT_STATES`), never a held row, never a claim and never a push. Stored 🚩 reads are last-wins per (session,
  symbol), so without this marker the placebo cohort could not be recovered.
- 🧪 holds ONE claim per (day, symbol, setup). A K3S ring on a 🎾 therefore blocks a LATER same-day 🚩 🎾 A+ on that
  name from being judged on 🧪. That A+ lands in `n_unjudged.claimed_before`, its ledger id is the same as the K3S
  claim's, and the compare counts it as `same_day_original` (HIS CALL #48). The nightly copies nothing for it: the
  plans differ, so it is a `residual`, graded on the K3S plan. While K3S rings, a non-zero `copy.residual` is normal.

## Costs

The 🎾 re-read runs only on a candidate's break pass: one detector call plus one `k11_gate` on frames already in
memory, with no fetch. Each 🎾 break writes at most one `#partial_break` marker per name per day. A K3S ring that the
nightly grades costs one `grade_step` load, the same as any 🚩 residual.

## Measurement (pre-registered; nothing is read before n ≥ 30)

- Primary: K3S rings, W / L / unfilled, mean R per ring, and the stop-out rate, beside 🚩's own 🎾 A+ rings on the same
  sessions, with the same grader and the same columns. The Wilson 95% interval is the lab's read at n ≥ 30. The tab
  serves mean R and filled beside every W / L.
- **🚩's 🎾 A+ arm may be ~empty for weeks.** It was 0 on 11-04 and 11-05. A one-arm read is NOT "positive". Which
  rate the decision rule uses when that arm is empty is HIS CALL #47.
- Placebo (a), 🎾 partial breaks on a rule other than K3: read from the `#partial_break` markers whose `k3s` is False.
- Placebo (b), 🎾 🧠 potentials that armed and never broke A+: read from the overlay docs' `frozen` memory.
- Out of sample: the first half of the sessions by date versus the second half.
- **Selection confound (K3S × G1):** K3S admits the loud-base reads, and G1 then keeps only the loudest breaks. The
  survivors measure a loud base AND a very loud break. The G1 hold share is served.
- Decision rule (prereg): positive at n ≥ 30 with the interval clear of 🚩's rate → a paper-lane variant ONLY on HIS
  CALL, never a 🚩 change from this file. Null or negative → K3S is turned OFF on 🧪, and the row stays as a record.
