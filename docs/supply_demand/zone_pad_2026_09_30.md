## 1. The one number

`level_pad.DEMAND_PAD_PCT = sd_liquidity.STOP_SHELF_PCT` (1.0) — the house "stop shelf", already
defined as "where the stops actually sit, as a band under the zone floor". Reused by name, never
retyped. `DEMAND_PAD_PCT = 0` turns the pad off everywhere (every value is read at call time) and
restores the pre-pad engine byte-for-byte; the kill-switch test pins that.

Worked example (every test uses it): band 133.00–135.00 demand → `support_floor` **131.67**;
phone / lane / holdings stop 131.67 × 0.995 = **131.01** (the paper stock lane's 4-dp stop is
131.0116 — 131.01165 in float); board plan stop 131.67 × 0.985 = **129.69**. Key level PWL 133.00
on the support side → `key_edge` 131.67; a close breaks it at ≤ 131.67 × (1 − 0.15%) = 131.4725
(131.47 breaks, 131.48 does not); before the pad it broke at ≤ 132.8005.

## 2. The rule, in one sentence

SUPPORT reads (in the zone / near demand / arrival / crossed / broken / the stop) use the padded
floor; RESISTANCE reads (a band above the print as a ceiling, room, target) use the drawn edges —
except that the band a read is ABOUT is never its own ceiling; the measured floor-held gate reads
the drawn floor (HIS CALL #1).

Drawn band edges and key-level prices NEVER move in any payload. Demand bands gain additive
`pad_lo` / `pad_pct`; key-level members and chart lines gain `pad_price`; the sweep read gains
`in_pad`; `price_zones.compute(..., demand_pad_pct=…)` adds `params.demand_pad_pct`. No ordering key
changes — only membership. Dedupe keys (`demand_alerts.state_key`, `zone_edge.break_state_key`,
`zone_edge.first_seen_key`, `zone_edge_entry.state_key`, `race_id`) and `zone_store` docs are built
from the drawn band, so nothing re-pushes on deploy day and nothing migrates.

## 4. Exactly how the standing phone gate changes (≥ 5% room + within 1% of demand)

- **Proximity:** before `lo ≤ px ≤ hi × 1.01`; after `lo × 0.99 ≤ px ≤ hi × 1.01`. The "1% above
  the top" is unchanged; the floor side reaches 1% lower.
- **Room:** `ALERT_MIN_ROOM_PCT` 5.0, unchanged number, unchanged targets (supply bands and broken
  demand bands measured to their DRAWN bottom). The only change: when a caller names the band the
  push is about (`entry_band`) and that band is PADDED, it is never its own ceiling — before the pad
  it could not be (the print had to be inside it), so this matters only for prints inside its pad.
  A supply shelf named as the entry band changes nothing (pinned).
- **Net phone effect with the defaults: the set of pushes is unchanged.** A print inside a band's
  pad has a day low under the drawn floor → `sweep_read` (drawn floor, plus the corner guard for an
  unknown day low) reads swept / broken → `floor_held_gate` refuses it. Pinned by
  `test_the_phone_set_is_identical_with_the_pad_on_and_off` (one real `zone_edge.check_once` pass,
  pad on vs off). What changes on the phone: the plan line's stop (131.01, not 0.5% under 133), its
  risk % (+≈1pp) and its R. Flipping HIS CALL #1 is what lets a 132 print ring.
- `approach_read` "reclaiming" becomes rarer (a prior close inside the pad is not "from below");
  `demand_alerts.read` counts a prior close inside the pad as residence, not an arrival — both only
  tighten the PHONE. The paper demand lane reads the same arrival and has no floor-held gate, so it
  changes both ways (HIS CALL #9).

1. **Floor-held gate reads the drawn floor** — `level_pad.PAD_FLOOR_HELD = False`. Flip = his 132

4. **Stops stack under the pad** — `alert_gates.STOP_BUFFER_PCT` 0.5 / `demand_reentry.STOP_BUFFER_PCT`

5. **Sell timing** as in §6 — every change listed there stays. **DECIDED 2026-10-01**, Ajay: "Both

6. **Undercut tolerances are not stacked** — `zone_bounce_alerts.WICK_PCT` 1.5,

7. **One knob** (`DEMAND_PAD_PCT = sd_liquidity.STOP_SHELF_PCT`) for zones AND key levels, coupled

8. **Scope**: fine geometry (Support tab's finer levels, the zones page, the Tape tab, Under Value

9. **Paper lanes may enter inside the pad** (`zone_edge_entry.alert_gate` has no floor-held gate).

11. **Trade autopsy** keeps the drawn floor for band_failed / shakeout.
12. **Room entry-band exclusion** — the band a push is about is never its own ceiling, even when the
