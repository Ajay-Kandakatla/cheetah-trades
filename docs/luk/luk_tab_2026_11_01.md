## What the tab is

- **Its own package** `backend/chart_maps/luk/`, modeled file for file on `chart_maps/gajjala/`. It reuses GG's GENERIC
  primitives by import (Frames, `build_frame`, `closed_only`, `tile_payload`, the lease helpers, the dry recorder, the
  detached-spawn `_popen`, the claim/shadow keys, the ledger fill primitives, the tape payload) and copies no GG logic.
- **Its own `Variant` instance** `LUK` (`luk/variant.py`), never registered in GG's `variant.by_key`. Claims
  `LUK:{date}|SYM|setup`. `gajjala.variant.push_mode(LUK)` is "shadow" by construction (GC has no `LUK_PUSH_MODE` →
  fail closed).
- **Its own store** `LukStore(GajjalaStore)`: every logical collection is injected as `luk_passes`, `luk_reads`,
  `luk_alerts`, `luk_state`, `luk_ledger`, `luk_daily`, plus `luk_screens`. The unused GG names (scan, ah-carry, post,
  halts, potentials, replay, overlay) are a refusing stub — `🥇 Luk never touches gajjala_<name>`. The lease numbers are
  Luk's own (`LUK_LEASE_SEC`, `LUK_LEASE_MIN_GAP_SEC`); the inherited override matters, because the base class hands any
  non-GG5 variant the 55 s one-minute lease.
- **Frames** `1m · 5m · 60m`. 1m and 5m carry pre-market, regular and after-hours bars; the 60m frame is regular-session
  minutes only (`LUK_HOURLY_SESSION`), resampled clock-anchored by the house `resample_ohlcv` — its ema9/ema21 are his
  hourly 9/21.
- **One pass per 5-minute tick, a DETACHED child.** The ONE edit to the gajjala package is `_spawn_luk()` in
  `chart_maps/gajjala/run.py`, called on the line right after `_spawn_1m()` on the cron path only. It spawns
  `python -m chart_maps.luk.run --child` (the run_1m pattern: new session, close_fds, tini reaps it) only when
  `luk.run.enabled()` and `luk.run.in_window()`. It is fenced: one log line, never raises, never changes the exit code,
  never on `--dry-run` / `--now` / `--on-demand` / `--symbols`. The permanent pin is STRUCTURAL
  (`tests/test_luk_gajjala_hook.py`: the AST holds exactly one `_spawn_luk` def and one call, right after `_spawn_1m()`),
  never a byte manifest.
- **Kill switch.** `LUK_ENABLED` (constant) and env `LUK_ENABLED=0` on the cron container. The tests run with the env "0"
  (assigned inside conftest's session fixture, restored on teardown).
- **Pushes: LIVE since 2026-11-01 by his word** ("Lets make it live. also alerts too." — GO-LIVE above).
  `LUK_PUSH_MODE = "live"`, kind `luk_setup` (OWNER_KEEP_SET's seventh kind, default False for everyone else), sender

|---|---|

**The per-frame A+ rule** (HIS CALL #26).

- **5-minute frame:** GG's rule verbatim — the break bar is the LATEST closed 5-minute bar ("traded through the trigger
  and closed"). A skipped pass → `triggered`, as on 🚩.
- **1-minute frame:** the break bar closed AFTER the previous Luk pass's bars-through (`luk_state` key
  `LUK_STATE_BARS_THROUGH` = `{session, t1, t5, at}`; None on the first pass → any bar today) AND no later closed 1-minute
  bar has low ≤ stop. Why: one pass per 5-minute tick reads 1–5 one-minute bars at once. GG's latest-closed-bar rule
  would discard 4 of 5 one-minute triggers and every ORH take-out on 09:32–09:34; with this rule a 09:32 break read at the
  09:36 pass rings.
- **The latency fact (HIS CALL #5, #29):** a 1-minute trigger is read on the next 5-minute pass — up to 5 minutes after
  its bar closed — and still rings when no later bar touched the stop. The gate's freshness clock is
  `gajjala.alerts.max_entry_age_sec(LUK)` = 300 + 30 = 330 s; after a skipped pass the detector may still say `aplus` and
  the gate records "#late".

## The stop plan

## Traps

- **The hook runs in every existing 🚩 test that calls `RUN.main([])`.** Without conftest's `LUK_ENABLED=0` a REAL
  detached process would spawn from the test suite. The conftest ASSIGNS the env (never `setdefault`, which an exported
  `LUK_ENABLED=1` would defeat); the hook tests set "1" explicitly.
- **Never hand the Luk variant or store to GG's served helpers.** `gajjala.variant.served_block/word/_record_from` and
  `gajjala.ledger.grade/rows_for` read `GC` attributes that do not exist for Luk (AttributeError). An import guard lists
  the allowed `gajjala.ledger` names.
- **The lease override is load-bearing.** `GajjalaStore._lease_nums` returns the 55 s one-minute lease for any non-GG5
  variant; a 120 s Luk pass under it could be re-claimed.
- **The house daily cache holds half-session bars, and `patch_latest_closes` re-stamps `cached_at` without rewriting
  the rows under it** — no house doc is a close proof. Every Luk closed-day read (screens, grade, index words) is Luk's
  own `load_prices(force=True)` after the settle; never `_mongo_get`, `load_prices(force=False)`, `closed_daily_frame`
  or `cached_frame_meta`.
- **Lookbacks through the judged bar.** `rth_low(F)` without `through_t` is the whole-day low and would flip reads
  retroactively; `hourly_ref` is per bar because the 10:00 hourly bar contains the flush itself.
- **GG's latest-closed-bar A+ rule is wrong on the 1-minute frame** under a 5-minute cadence (it discards 4 of 5
  triggers); the 5-minute frame keeps it.
- **Hourly bars are clock-anchored** (house rule); TradingView anchors 09:30, so EMA values differ from his chart.
- **Pre-open the snapshot's day bar is zeros** and there is no prev-day volume: price×volume on pre-market passes comes
  from the daily cache, never from the snapshot's day volume.
- **`extended_print` dates:** a pre-market print must be dated the session or it is yesterday's print.
- **First appearance loads up to 10 prior sessions** per name; the `frames_for` deadline comes first so the pass still
  ends inside its slot.
- **The hook checks the window too** — a child spawned 16:06–20:01 only to write "skipped" is ~48 wasted Python starts a
  day.
- **Host venv is Python 3.9:** `Optional[...]`, never `X | None`, no `match`.
- **Never `vite build` in the workflow** (1.43 GB); tsc + vitest only.
- **The words.** Every served string and every comment in the Luk package says "reversal"; the transcript fixtures keep
