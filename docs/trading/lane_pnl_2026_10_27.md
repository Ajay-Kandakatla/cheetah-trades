## What the block shows

On the Auto-Pilot Dashboard (`/trading?view=dashboard`), under the account line and the alarm strips (no-stop / engine
issues stay above), above Positions: the title "💵 Which lane made money", one served verdict sentence, then one row per
lane that traded (🚩 Gajjala, 📈 Minervini SEPA, 🧲 demand zone, 🚀 breakout (S/D supply band), 🗞️ catalyst, 🎛️ Options,
🎯 0DTE, 🔥 hot pullback, ✋ manual), sorted by total $ (realized + open on what the broker holds), each with:

- the total $ (coloured by its served `tone`),
- `N closed · W W / L L · P% won`, `realized $…`, `open $… on N held` (or "nothing held at the broker" / "nothing open"),
- the first → last ET day the lane traded, and a link to the lane's tab (🚩 Gajjala tab, Options tab, 0DTE tab, else the Journal),
- an amber note when a row has sells without a booked fill or open book rows the broker does not hold.

Below the rows: "No trades yet: …" for lanes that never traded, the account line (`Account since YYYY-MM-DD: total
(closed · open)`), the part of the account no lane explains ("Not attributed to a lane: … — the account's P&L minus every
lane's book."), and the honesty line. Every word and every number is served by `journal.lane_pnl`; the component prints
strings only, formats no number, and wraps at 430 px (no table).

## Where every number comes from

| number | source |
|---|---|
| realized $ (stock lanes) | `journal.summary()["by_strategy"][lane]["realized_pnl"]` — Σ `gain_dollars` of the lane's closed journal docs |
| realized $ (🚩 Gajjala) | the lane's own book: the `gajjala_exit` ledger row / `gajjala_lane` doc `pnl_usd` per alert id (`realized.source == "lane_book"`) |
| realized $ (🎛️ Options) | `options_lane.journal_block()` (the `options_positions` book) |
| realized $ (🎯 0DTE) | `zero_dte_lane.journal_block()` (the `zero_dte_positions` book), merged as the `zero_dte` row |
| open $ | the broker's `unrealized_pl` on what it holds NOW (`broker.positions()`), stock by the newest open journal doc of the symbol, options by the lane's open OCC contracts |
| wins / losses / win % | `by_strategy` (closed trades with gain > 0 / < 0) |
| dates | `by_strategy[lane]["first_ts"]` / `["last_ts"]` as ET days |
| account total | `pnl_summary.total_pnl_dollars` (equity − the `trading_account_baseline` starting equity) |
| account open | Σ `unrealized_pl` over every broker position; account closed = total − open (a residual) |
| not attributed | account closed / open minus Σ every lane's realized / open |

`GET /trading/status` (admin, polled every 10 s) serves the block as `lane_pnl`; it reuses the options / 0DTE blocks
status already built and reads only the persisted journal docs (never `reconcile()` there). `GET /trading/journal`
serves the same `summary.by_strategy` — one function, the same numbers.

## The fixes

1. **Phantom open rows (11).** The exit engine's market sells (`distribution_exit`, `watchdog_exit`, and the 🔥 lane's
   `hot_pullback_exit`) and fill-less `flatten` rows never booked a fill, so these journal rows stayed "open" forever
   with fake marks: **ATI, SLAB, PNTG, CNQ, ASX, PR, EMR, LNG, FRSH, SM, MRK** (ASX carried 4 `watchdog_exit` rows — one
   candidate; SLAB's decision qty is 6 against the entry's 56). Each now waits for the broker's own fill
   (`fill_wanted`); `exit_fills.book()` books it as ONE `exit_fill` ledger row at the fill price and fill time. Until a
   fill is booked the row says "Sold at market by the engine on <day> (<kind>); the broker's fill is not booked yet.", is excluded
   from realized $ and open $, gets no fake mark on `/trading/journal`, and its dollars sit in "not attributed".
2. **🚩 Gajjala double rows.** The lane's breakeven add wrote a second `entry` row, and both rows paired with the same
   exit (often a fill-less `flatten`, so realized $ was null). Now one journal trade per ALERT id: the add merges into
   its alert's trade, and realized $ comes from the lane's own `gajjala_exit` / `gajjala_lane` book. The 3 stale add
   docs already in `trade_journal` — **SXTP-1793113863, VIVK-1792698067, SHFS-1792687265** — are marked
   `superseded: true` (`superseded_by` = the main trade id, `superseded_reason` = "🚩 breakeven add — merged into its
   alert's trade") and never deleted; `load()` and `summary()` skip them.
3. **0DTE row.** `zero_dte` was absent from `by_strategy`; it is merged from the lane's own block (n = open + closed).
4. **🔥 hot pullback tag.** Inferred in the journal from `entry_reason.lane == "hot_pullback"` (the ledger row still
   says "manual"; `entries.STRATEGIES` unchanged).
5. **Rows without epoch.** `hot_pullback_exit` rows carry an ET-offset `ts` and no `epoch`; the ledger reader derives
   the epoch from `ts` so they sort at their real time.
6. **Header option cost basis.** `pnl_summary` now subtracts the option positions' cost basis, so the Dashboard
   header's unrealized no longer counts the spreads' full market value as gain (HIS CALL #3).

## Why `exit_fill` and not `trade_closed`

`trade_closed` is an ENGINE INPUT: `entries._closed_trade_stats()` feeds the p.299 half-average-gain stop rule and
`progressive.last_gains()` feeds pilot sizing. Writing back-filled `trade_closed` rows would change future stops and
sizes. `exit_fill` is read by the journal only; `entries.py` and `progressive.py` never name it (pinned by
`backend/tests/test_trading_contracts.py::test_lane_pnl_2026_10_27_accounting_only` and the contracts block
"💵 Auto-Pilot P&L by lane (2026-10-27)").

## Matching rules (BUILD_SPEC28 §3.13, verbatim)

```python
SOURCE_LIVE = "broker_fill"
SOURCE_BACKFILL = "broker_fill_backfill"
CITE = "broker fill of the engine's market sell (accounting only)"
def book(brk, *, held_symbols: Optional[set] = None, skip_symbols: Optional[set] = None,
         lookback_days: Optional[float] = None, source: str = SOURCE_LIVE, dry_run: bool = False,
         now: Optional[float] = None) -> dict
def rollback(dry_run: bool = True) -> dict
def _main(argv) -> int        # python -m trading.exit_fills backfill --dry-run | --live ; rollback --dry-run | --live
```
Imports: `from trading import exit_engine as EE`, `from trading import journal as JN`; use `EE._db()` and `EE.ledger(...)` through the module (tests monkeypatch). Never import a broker module (the broker comes in as `brk`).

`book()` algorithm:
0. `EE._db()` is None → return `_out(candidates=0, skipped="no ledger")`.
1. Tick pre-check (`lookback_days is not None`): `rows = list(EE._db().trade_ledger.find({"kind": {"$in": list(JN.FORCE_EXIT_KINDS + JN.FILLLESS_EXIT_KINDS)}}))`, keep non-dry rows with `_epoch ≥ now − lookback_days*86400`; none → return `_out(candidates=0)` with no other read.
2. `reader = getattr(brk, "closed_orders_for", None)`; not callable → return `_out(skipped="broker has no closed_orders_for")`.
3. `cands = JN.unbooked_exits()`; when `lookback_days` set, keep `c["epoch"] ≥ cutoff`.
4. `held_symbols is None` (back-fill): `held = {stock symbols of brk.positions()}`; failure → return `_out(errors=["positions unavailable: …"])` and book nothing.
5. `booked_ids` = every `detail.order_id` and every `detail.order_ids[*]` of ledger rows with kind in ("trade_closed", "exit_fill").
6. Per candidate (symbol S upper): `S in skip_symbols` or (`c.queued` and S in skip_symbols) → `skipped_queue`; `S in held` → `still_held`; else `orders = reader(S, after_iso=c.entry_ts, until_iso=c.window_end_ts)`; `sells` = orders with `side == "sell"`, `float(filled_qty or 0) > 0`, `filled_avg_price` set, `id not in booked_ids`, symbol S, sorted by `filled_at`. None → `no_fill`. Else `cap = min(x for x in (c.entry_qty, c.held_qty) if x)` (None when both missing); take greedily `take_i = min(filled_qty_i, cap − taken)` until cap; `sold = Σ take`; `overfill = Σ filled_qty − sold` when cap set; `fill = round(Σ take×px / sold, 4)`; `gain_pct = round((fill / c.entry_price − 1) * 100, 2)` if entry_price else None; `partial = cap is not None and sold < cap`.
7. Write (unless dry_run) `EE.ledger(JN.EXIT_FILL_KIND, symbol=S, detail=D, dry_run=False, cite=CITE, at=<filled_at of the last used sell, aware UTC>)` with
```
D = {"leg": "force_exit" if c.kind in JN.FORCE_EXIT_KINDS else "flatten", "source_kind": c.kind, "source": source,
     "trade_id": c.trade_id, "strategy": c.lane, "order_id": used[0].id, "order_ids": [o.id for o in used],
     "fill": fill, "qty": sold, "entry": c.entry_price, "gain_pct": gain_pct, "decision_ts": c.ts,
     "decision_last": c.last, "held_qty": c.held_qty, "reason": c.reason, "filled_at": used[-1].filled_at,
     "partial": partial, "overfill_qty": overfill or 0, "est": False}
```
   plus `"backfilled_at": EE._utc_iso()` when `source == SOURCE_BACKFILL`. Add the used ids to `booked_ids` (no reuse in one run).
8. Return `{"candidates": n, "written": [rec], "would_write": [rec], "no_fill": [sym], "still_held": [sym], "skipped_queue": [sym], "partial": [sym], "overfill": [sym], "skipped": None|str, "errors": [str]}` with `rec = {"symbol", "lane", "trade_id", "qty", "fill", "entry", "realized": round(qty×(fill−entry), 2)|None, "orders": len(used)}` ("written" live, "would_write" dry).

Idempotency: a booked candidate becomes a closed doc (its `exit_fill` is the next exit after the entry) so `unbooked_exits` no longer lists it; used order ids are in `booked_ids`.
NEVER: submit/cancel/replace/close, `_notify_autopilot`, any write but `EE.ledger(...)` and the single scoped `delete_many` in `rollback`.

`rollback(dry_run)`: filter exactly `{"kind": "exit_fill", "detail.source": SOURCE_BACKFILL}`; count; live → `EE._db().trade_ledger.delete_many(<that filter>)` then `JN.reconcile()`; return `{"rows": n, "deleted": n|0}`.

`_main(argv)`: `backfill --dry-run` → `book(EE.broker, source=SOURCE_BACKFILL, dry_run=True)`; `backfill --live` → same with `dry_run=False`, then `JN.reconcile()`, then print `JN.summary()["by_strategy"]` keys → (closed, open, realized_pnl, unbooked). Output line per candidate, exact format: `"%-6s %-13s entry %s %s @ %s · %s %s · %s"` % (symbol, lane, entry ET day, entry_qty, entry_price, kind, decision ET day, outcome) where outcome ∈ `"%d sold @ %s (%d order%s) · realized %s WOULD WRITE"` (dry) / `… WRITTEN` (live) / `"NO FILL FOUND — left open"` / `"STILL HELD — skipped"` / `"IN FLATTEN QUEUE — skipped"`. First line `"exit_fills backfill — DRY RUN (nothing written)"` or `"exit_fills backfill — LIVE"`; last line `json.dumps(result-without-rec-lists-but-with-counts, sort_keys=True)`. `rollback --dry-run|--live` prints one line + JSON. Return code 0, 1 when `errors`. No broker key or URL is ever printed (BrokerError text is pre-scrubbed, broker_alpaca.py:85-95).

## Back-fill runbook (BUILD_SPEC28 §7)

## HIS CALLs (BUILD_SPEC28 §8, verbatim)

1. **Engine-sell fills are journal-only (`exit_fill`)** — they do NOT feed the p.299 half-average-gain stop rule (`entries._closed_trade_stats`) or progressive pilot sizing (`progressive.last_gains`); both stay byte-identical. Counting the 11 force exits there would change future stops/sizes. Default: not counted.
2. **No broker fill found → no number.** The row stays open, flagged "sold without a booked fill"; its dollars sit in "not attributed to a lane". Alternative: book the decision `last` as `est: true` into realized $. Default: no estimate.
3. **Header fix:** the Dashboard header's hover realized/unrealized now subtracts the option positions' cost basis (unrealized "$3,146" → about "+$851", realized "−$14,166" → about "−$11,871"); it was counting the 3 spreads' full market value as gain. Default: fixed in this build (one argument; veto = revert).
4. **Ranking and "net positive" use total $** (realized + open on what the broker holds), not win rate; an open gain can make a lane "net positive". Default: total $.
5. **0DTE row:** `n` = open + closed (the 11 missed orders excluded — differs from the 0DTE tab's n = 74); `expectancy_pct` = the lane's `avg_premium_return_pct`; `avg_r` null. Default: as stated.
6. **🔥 hot pullback tag** inferred in the journal from `entry_reason.lane`; `entries.STRATEGIES` unchanged (the ledger row still says "manual"). Default: journal-only.
7. **Lane books not repaired here:** the 2 stale 0DTE open docs (IWM 2026-09-29, QQQ 2026-09-30) are shown as "not held at the broker" with their P&L in "not attributed". Default: shown, not repaired.
8. **Lanes that never traded** (🗞️ catalyst, 🔥 hot pullback) get one "No trades yet: …" line, not empty rows (dense surface). Default: one line.
9. **Placement:** under the account line, after the alarm strips (no-stop / engine issues stay above), above Positions. Default: as stated.
10. **Entry basis stays the journal's planned entry price/qty** for the stock lanes (🚩, options, 0DTE use their own books); slippage lands in "not attributed". Booking the broker's BUY fills too would be a wider change. Default: not done.
