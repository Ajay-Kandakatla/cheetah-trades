## 2024-05-18 - ARIA tags for expandable text truncation
**Learning:** Expanding/collapsing inline text sections requires accessibility state tracking so screen reader users know the truncation status. Specifically, when a "Show more" toggle is used, it should expose its current state via `aria-expanded` and link to the truncated content container via `aria-controls`. This pattern was identified and fixed in `CompanyAbout.tsx`, bringing it in line with similar popover patterns (like `InfoButton.tsx`) which correctly implemented `aria-expanded` in this app.
**Action:** Always verify that "Show more" or truncation toggle buttons include `aria-expanded` tied to the local state, and `aria-controls` mapped to a uniquely generated `id` on the text container (e.g., using the symbol identifier if multiple instances might exist on the page).
